# How To Start (пошаговый план для новичка)

Этот файл — твой спасательный круг. Делай пункт за пунктом, не пропускай.

---

## Когда дали новую задачу (например, "сделать карточку отеля")

### Шаг 1. Понять, что это: блок или страница?

- **Блок** — кнопка, карточка, инпут, шапка. Живет в `src/blocks/`
- **Страница** — ui-kit, поиск, результат. Живет в `src/pages/`

**Вопрос к себе:** "Буду ли я использовать эту штуку в другом месте?"
- Да → блок
- Нет → может быть страница или специфичный блок

## Алгоритм создания нового блока

### 1. Создаю папку блока

```
src/blocks/имя-блока/
```

Имя блока:
- только маленькие буквы
- дефис вместо пробела
- существительное: `card`, `button`, `search-form`

Неправильно `mySuperButton`  
Правильно `my-super-button`

### 2. Создаю файл разметки

`src/blocks/имя-блока/имя-блока.pug`

```pug
.имя-блока
  .имя-блока__элемент1
  .имя-блока__элемент2
```

**Пример для карточки:**
```pug
.card
  img.card__image(src="img.jpg" alt="описание")
  h3.card__title Заголовок
  p.card__text Какой-то текст
  button.card__button Купить
```

### 3. Создаю файл стилей

`src/blocks/имя-блока/имя-блока.scss`

```scss
.имя-блока {
  // стили самого блока
  
  &__элемент1 {
    // стили элемента
  }
  
  &__элемент2 {
    // стили элемента
  }
  
  &--модификатор {
    // стили измененного варианта
  }
}
```

**Пример:**
```scss
.card {
  border: 1px solid #ccc;
  padding: 16px;
  
  &__image {
    width: 100%;
  }
  
  &__title {
    font-size: 18px;
    font-weight: bold;
  }
  
  &--large {
    width: 400px;
  }
}
```

### 4. Если блоку нужна логика

Создаю `src/blocks/имя-блока/имя-блока.js`

```javascript
(function() {
  // вся логика только для этого блока
  const block = document.querySelector('.имя-блока');
  if (!block) return;
  
  // твой код здесь
})();
```

## Алгоритм подключения блока на UI Kit

### 1. Открываю `src/pages/ui-kit.pug`

### 2. Добавляю include в начало файла

```pug
include ../blocks/имя-блока/имя-блока.pug
```

### 3. Добавляю демонстрацию блока в тело страницы

```pug
h2 Имя-блока
.example-wrapper
  +имя-блока()
  
h2 Имя-блока с модификатором
.example-wrapper
  +имя-блока({ modifier: 'large' })
```

**Как это работает:** `+имя-блока()` вызывает Pug-миксин, который ты написал в `.pug` файле.

---

## Алгоритм использования блока на странице поиска

### 1. Открываю `src/pages/search.pug`

### 2. Добавляю include в начало (если ещё не добавлен)

```pug
include ../blocks/имя-блока/имя-блока.pug
```

### 3. Вставляю блок в нужное место

```pug
.search-page
  .search-page__filters
    +имя-блока()
```

## Порядок работы над задачей (не нарушать!)

1. **Сначала блок** — создал, сверстал, на UI Kit проверил
2. **Потом коммит** — `feat: add имя-блока block`
3. **Потом страница** — использовал блок на странице поиска
4. **Потом коммит** — `feat: add имя-блока to search page`

**Золотое правило:** Никогда не делай новую фичу, пока не закоммитил старую.

## Частые косяки (проверяй перед тем как сказать "готово")

### Разметка
- [ ] У всех `img` есть атрибут `alt`
- [ ] Ссылки на чужие сайты имеют `target="_blank"` и `rel="noreferrer"`
- [ ] Использованы семантические теги (`header`, `main`, `footer`, `nav`) вместо `div`

### Стили
- [ ] Нет `!important`
- [ ] Нет вложенности больше 2 уровней
- [ ] Нет селекторов по тегу (`div`, `h1`, `button`) — только классы
- [ ] Нет классов в стиле `camelCase` (только `kebab-case`)

### БЭМ
- [ ] Имя блока — существительное
- [ ] Имя модификатора — прилагательное
- [ ] Нет элементов от элементов (`.block__element1__element2`)

### Работоспособность
- [ ] Страница открывается без ошибок
- [ ] UI Kit показывает все состояния компонента
- [ ] На кнопках и ссылках появляется пальчик (`cursor: pointer`)

## Если завис — чек-лист

1. Правильно ли указан путь в `include`?
2. Не забыл ли создать `.pug` файл в папке блока?
3. Не забыл ли создать `.scss` файл в папке блока?
4. Подключен ли SCSS файл в глобальную сборку? (если вручную — добавить в `main.scss`)
5. Нет ли синтаксической ошибки в Pug (например, пропущен отступ)?
