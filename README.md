# Metalamp Task 2

Frontend training project from Metalamp education program.

## Description

Implementation of the hotel booking website layout based on the provided Figma design.

## Technologies

* HTML
* Pug
* SCSS
* JavaScript
* Parcel
* Git

## Installation
